## How it works

- `draw.py` (Python + Pillow, DejaVu fonts, shapes only: no photos or third-party artwork) draws the 1024x1024 poster `entry.png`.
- `main.ts` (Node 22, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed and exiting non-zero with a clear message if the copy fails.

Run: `python3 draw.py && MAKEFUN_OUTPUT_DIR=out node main.ts`
